# Игра «5 букв»
Словесная головоломка, в которой нужно угадать загаданное слово из 5 букв за 6 попыток.

## Описание проекта
«5 букв» — классическая игра-головоломка (аналог Wordle), разработанная на Python с использованием библиотеки Tkinter. Игрок угадывает случайное слово из пяти букв, получая цветовые подсказки.

## Функциональные возможности
- Случайный выбор слова из словаря
- 6 попыток для угадывания
- Цветовая подсветка букв (зелёный, жёлтый, серый)
- Виртуальная экранная клавиатура
- Поддержка физической клавиатуры
- Проверка слов по словарю
- Добавление новых слов в словарь
- Защита от повтора слов в одной игре
- Экраны победы и поражения

## Управление
- Ввод букв: экранная клавиатура или физическая клавиатура (русская раскладка).
- Удалить: Backspace или кнопка «Удалить».
- Отправить: Enter или кнопка «Ввод».
- Выход: Esc.

## Технологии
- Python 3.13
- Tkinter
